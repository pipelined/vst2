## `vst2`

[![PkgGoDev](https://pkg.go.dev/badge/github.com/cwbudde/vst2)](https://pkg.go.dev/github.com/cwbudde/vst2)
[![Go Report Card](https://goreportcard.com/badge/github.com/cwbudde/vst2)](https://goreportcard.com/report/github.com/cwbudde/vst2)
[![Test](https://github.com/CWBudde/vst2/workflows/Test/badge.svg)](https://github.com/CWBudde/vst2/actions?query=workflow%3ATest)

`vst2` implements VST2 SDK API. It provides capabilities to build both VST2 hosts and plugins.

This is a fork of [pipelined/vst2](https://github.com/pipelined/vst2), maintained at
`github.com/cwbudde/vst2`. The module path was changed accordingly, so it can be
consumed with `go get` directly and without a `replace` directive.

## Installation

```bash
$ go get -u github.com/cwbudde/vst2
```
